# Project: shad.tool server

## Git

- Remote: `git@github-shadtool:shadtool/server.git` (uses `github-shadtool` SSH host alias)
- The `github-shadtool` host alias in `~/.ssh/config` routes to the `id_ed25519_shadtool` key
- Always push/pull using this remote — do NOT use `git@github.com:...` directly, as it would use the wrong SSH key
